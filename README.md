# ShpioniroGolubiroAgent

Telegram-бот для Telegram Business: сохраняет удалённые и изменённые сообщения, а также
одноразовые медиа (при ответе на них). Меню, карточки событий и тексты повторяют референс.

Работает только в личных диалогах подключённого аккаунта. Стек: Python 3.11+, aiogram 3.22+,
SQLite (встроенный `sqlite3`, без лишних зависимостей).

## Что умеет

| Раздел | Что делает |
|---|---|
| 👤 Профиль | Счётчики удалённых / изменённых и время с момента подключения |
| 🔔 Уведомления | Переключатели: свои действия, изменения, удаления, боты |
| 🗃 История | Все события, по 15 на страницу, ◀️ 🔄 ▶️, по нажатию приходит карточка |
| 🕵️ Spy | Ответ на одноразовое медиа, и копия приходит в бот |
| 🛠 Юзербот | `.mute`, `.type`, `.clock`, `.help` (спам и «шакализатор» убраны) |
| ℹ️ Инфо | Инструкция по подключению |

События (удаление, изменение, одноразка) всегда пишутся в историю. Настройки уведомлений
управляют только тем, приходит ли сообщение в чат.

## Запуск

1. Создайте бота у @BotFather, возьмите токен.
2. В @BotFather: `/mybots` → ваш бот → **Bot Settings → Business Mode** → включить.
   Если есть режим тем (Threaded Mode), включите его: тогда появятся вкладки
   «Изменённые» и «Управление» как на скриншотах. Без него бот работает в обычном чате.
3. Установка:
   ```bash
   python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   cp .env.example .env        # вставьте BOT_TOKEN
   python main.py
   ```
4. В Telegram: **Настройки → Автоматизация чатов**, укажите `@ShpioniroGolubiroAgent`
   и выдайте права: читать сообщения, **управлять сообщениями** (нужно для `.mute`, `.type`),
   **изменять имя** (нужно для `.clock`).
5. Откройте бота и нажмите `/start`. После этого бот пришлёт подтверждение и меню.

## Деплой с iPhone: GitHub + Render.com

Premium для подключения не нужен. Всё делается из Safari.

1. **GitHub.** На github.com создайте репозиторий (New → Private). Нажмите **Add file →
   Upload files** и загрузите файлы проекта. Папки `app` и `app/handlers` загрузите так же,
   через Files-приложение выберите всю папку. Файл `.env` не загружайте (токен нельзя
   светить в репозитории; `.gitignore` это уже учитывает).
2. **Токен.** В @BotFather: `/newbot` (или `/mybots`), включите Business Mode, скопируйте токен.
3. **Render.** На render.com: **New → Blueprint**, подключите репозиторий, Render сам
   прочитает `render.yaml`. Когда спросит `BOT_TOKEN`, вставьте токен. Нажмите Apply.
   Если Blueprint не удобен: **New → Web Service**, Build Command
   `pip install -r requirements.txt`, Start Command `python main.py`, Instance Type
   **Free**, в Environment добавьте `BOT_TOKEN`.
4. Дождитесь статуса **Live**, в логах появится «Запущен @…».
5. В Telegram: Настройки → Автоматизация чатов → `@ShpioniroGolubiroAgent`, затем `/start` в боте.

Особенности бесплатного Render:
- Сервис без входящих запросов засыпает через 15 минут. Бот сам пингует свой адрес раз в
  10 минут, поэтому спать не должен. Бесплатных часов (750 в месяц) хватает на один сервис.
- **Диск временный.** При перезапуске или новом деплое файл базы стирается: пропадёт история
  и сохранённые копии сообщений. Чтобы данные жили постоянно, нужен платный план с Disk
  (путь монтирования, например `/data`, и переменная `DB_PATH=/data/bot.db`).

## Команды юзербота

Пишутся в личном чате от вашего имени. Команда сразу удаляется, чтобы собеседник её не видел.

- `.mute`: режим игнора в этом чате, новые сообщения собеседника удаляются. Повтор выключает.
- `.type текст`: печатает текст эффектом печатной машинки.
- `.clock` / `.clock Имя`: имя аккаунта вида `Имя | 22:05`, обновляется раз в минуту. Повтор выключает.
- `.help`: справка (приходит в бот, а не в чат).

## Как работает сохранение одноразок

Telegram не помечает одноразовые сообщения отдельным флагом. Бот реагирует, когда вы отвечаете
на медиа, которого он раньше не получал как обычное. Если нужно сохранять копию при ответе на
любое медиа, включите в разделе Spy «Любое медиа при ответе». Повторно одно и то же медиа бот
не присылает.

## Настройки (`.env`)

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен бота |
| `TZ` | часовой пояс карточек (по умолчанию `Europe/Moscow`) |
| `RETAIN_DAYS` | сколько дней хранить копии сообщений (по умолчанию 30) |
| `USE_TOPICS` | `1` / `0`: вкладки в личке бота |
| `CHANNEL`, `INSTRUCTION_URL` | необязательно: канал в инструкции и ссылка для «Читать инструкцию» |

## Что важно знать

- Бот видит и хранит копии сообщений вашего аккаунта. Копии старше `RETAIN_DAYS` удаляются,
  записи в истории остаются. Файл `data/bot.db` содержит переписку: не публикуйте его.
- Удалённое сообщение можно показать, только если бот получил его раньше. Всё, что было
  удалено до подключения или пока бот был выключен, восстановить нельзя.
- Тексты лежат в `app/texts.py`, кнопки в `app/keyboards.py`.

## Структура

```
main.py                запуск
app/config.py          настройки из .env
app/db.py              SQLite
app/texts.py           тексты и карточки
app/keyboards.py       клавиатуры
app/services.py        отправка, темы, разбор сообщений
app/clock.py           имя по времени и очистка
app/handlers/business.py   события бизнес-аккаунта и команды .mute/.type/.clock
app/handlers/private.py    /start и меню
render.yaml            конфиг деплоя на Render
```
